# 🎓 Estudos — Ciência da Computação

Repositório dedicado aos **estudos, atividades práticas e projetos desenvolvidos durante minha graduação em Ciência da Computação**.

O objetivo deste repositório é manter um registro organizado de parte da minha trajetória acadêmica, reunindo desde exercícios e experimentações com diferentes tecnologias até projetos desenvolvidos ao longo das disciplinas.

---

## 📂 Conteúdo do Repositório

O repositório reúne principalmente:

- projetos acadêmicos;
- projetos extensionistas;
- exercícios e atividades práticas;
- estudos de programação;
- desenvolvimento web;
- banco de dados;
- análise de dados.

---

## 🚀 Projetos em Destaque

### 🔥 Projeto Extensionista — Queimadas no Brasil

Projeto de análise de dados sobre **queimadas no Brasil e seus impactos ambientais**, desenvolvido a partir de dados públicos e informações de instituições de monitoramento ambiental.

Foram utilizadas técnicas de análise e visualização de dados com Python para investigar padrões temporais e geográficos relacionados às queimadas.

**Tecnologias:** Python · pandas · Matplotlib · Seaborn · scikit-learn · Jupyter Notebook

📁 [`projeto_extensionista_queimadas`](./projeto_extensionista_queimadas)

---

### 🏠 Projeto Extensionista — Casa Abrigo

Projeto extensionista desenvolvido durante a graduação, aplicando conhecimentos adquiridos no curso a uma problemática de interesse social.

📁 [`projeto_extensionista_casa_abrigo`](./projeto_extensionista_casa_abrigo)

---

### 🌐 Projeto Extensionista — RAD

Projeto desenvolvido na disciplina de **Desenvolvimento Rápido de Aplicações em Python (RAD)**, envolvendo a construção de uma aplicação web com integração entre front-end e back-end por meio de API.

O projeto utilizou tecnologias como Python, Flask, SQLite, JavaScript, HTML e CSS.

📁 [`projeto_extensionista_rad`](./projeto_extensionista_rad)
